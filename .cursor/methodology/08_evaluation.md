# 08 — Оценка: бенчмарк RU-Critical и гейты N/D-серии

Этот раздел — одновременно инженерный протокол и **главный научный вклад**
проекта. Бенчмарк цитируют чаще, чем модели.

Тезис **intelligibility-critical TTS** сохраняется без изменений: промоушен по
семантической точности (CER/DER/EER, text-usage), а не по MOS/UTMOS.

## Почему существующие метрики не годятся

Пять измеренных фактов, каждый из которых сам по себе публикуем. Ф1–Ф3 получены
в Part 1, Ф4–Ф5 — в фазе M.

**Ф1. Прокси-метрики проходят у тривиальных предикторов.** Part 1, эксперимент
E0: все четыре тривиальных baseline (константное среднее, копирование
предыдущего кадра, случайный латент корпуса, случайное чужое высказывание той же
длины) **проходят** legacy-гейты по длительности и стопу при oracle-длине.
Вывод зафиксирован в `docs/experiment_protocol.md`: `duration_in_band` и
`stop_success` не могут быть основанием для промоушена.

**Ф2. UTMOS не валидирован для русского.** Предиктор обучался на англоязычных
данных. В Gate V4 разница составила `delta_utmos = 0.005` при n = 100
(`out/gate_v4_v5_summary.json`) — статистически неотличимо от нуля, но
формально засчиталось как «UTMOS вырос». Решение по V4 было правильным по
другой причине (CER упал вдвое), но обоснование через UTMOS несостоятельно.

**Ф3. Средний CER маскирует критические отказы.** Реплика «переведите тысячу
двести тридцать четыре рубля», произнесённая как «тысячу двести тридцать пять»,
даёт мизерный вклад в средний CER и катастрофический — в прикладную пригодность.

**Ф4. Средний CER на `val100` насыщен.** Измерено в фазе M
(`out/baseline_track_a_critical.json`): синтез Track A даёт CER **0.031**,
реальная запись человека на тех же текстах — **0.060**, GT-мел через
нейровокодер — **0.064**. Синтез «лучше» человека означает, что метрика упёрлась
в шум ASR, а не измеряет качество. Порог вида «CER ≤ 15 %» на этом наборе не
различает системы.

**Ф5. Измеритель метрики сам может быть невалиден.** Два случая измерены в фазе M.
Первый: SA через текстовый ASR невозможна структурно —
`_strip_stress("за́мок") == _strip_stress("замо́к")`, поэтому на всех 895 позициях
`homograph` возвращался `skipped`. Второй: акустический детектор ударения на
длительности, энергии и F0 дал точность **0.358** на 779 словах реальной речи с
известным ударением (`out/m05_acoustic_sa_calibration.json`) при пороге годности
0.90. Метрика, измеритель которой не проверен, — не измерение.

**Ф6. Teacher-forced generative loss ≠ content.** Continuous N2 S1: ε-loss падает,
FR R² **−6.64**, Gate N2 FAIL
(`.cursor/results/n2_first_execution/RESULTS.md`). Для D1 промоушен только по
**free-running** ASR/CER/DER и text-usage; teacher-forced CE — диагностика.

Из Ф3 следует необходимость метрик по спанам; из Ф4 — медиан, CI и трудных
наборов; из Ф5 — валидация измерителя; из Ф6 — запрет масштабирования при FAIL
oracle ladder.

### Версионирование и аудит наборов

Заморозка хешами не означает непогрешимости набора. Аудит M01
(`docs/m01_eer_audit.md`): из 154 отвергнутых спанов `bank_entity` v1 в выборке
50 (seed 42) **54 %** — реальные ошибки синтеза, **46 %** — артефакты метрики.
Истинный EER оценён в **0.264** с ДИ [0.205, 0.332] против отчётных 0.489.

Отсюда обязательная процедура:

1. Каждый набор несёт поле `version` и sha256; хеши фиксируются перед серией.
2. Исправления вносятся **только новой версией**.
3. Выпуск версии сопровождается пересчётом baseline на неизменном чекпойнте.
4. До гейта — **аудит ошибок первого рода**.
5. Старые версии — диагностика / несравнимые точки.

### Метрики

Основные, специфичные для тезиса:

| Метрика | Определение | Порог |
|---------|-------------|-------|
| **DER** (digit error rate) | Доля неверно произнесённых цифр в критических спанах; по **словам-числительным** | целевой **0** |
| **EER** (entity error rate) | Доля критических спанов с любым расхождением | целевой **0** |
| **SA** (stress accuracy) | Доля корректных ударений на `homograph`, акустический детектор | ≥ 0.95 при валидированном измерителе |

Вспомогательные:

| Метрика | Роль |
|---------|------|
| CER / WER на hard-set / `val100` | Разборчивость; `val100` — sanity floor |
| Copy-synth topline | Потолок тракта (для D1 — Qwen3-TTS 12Hz decode) |
| Text-usage (shuffle/mask/prefix) | Обязателен на free-running ASR |
| Repeat/skip rate | Стабильность sampler/EOS |
| TTFB, RTF | Латентность; для телефонии — гейт (после content) |
| UTMOS | **Не** для promotion |

### Как измерять DER и EER

Процедура в `src/minispeech/eval/critical_spans.py`:

1. В эталоне размечены критические спаны.
2. Синтез → ASR.
3. Выравнивание **по словам**; спан в выровненном окне.
4. Допуск морфологии: общий префикс ≥ 4.
5. DER по словам-числительным после вербализации.
6. EER — по спанам целиком.

Нормализация обеих сторон одинаковая (`normalize_verbalized_for_asr`).

Числа P0 по старой процедуре объявлены невалидными; см. аудиты M01 / v3.

## Валидность измерителя как предусловие гейта

**Правило.** Метрика допускается в гейт только когда измерена точность
**измерителя** на реальной речи с известной истиной (n + CI).

| Метрика | Измеритель | Требование | Состояние |
|---------|-----------|------------|-----------|
| CER / WER | ASR | нижняя граница шума: запись человека | 0.060 на `val100` |
| DER / EER | ASR + align + verbalize | аудит ошибок первого рода | v1: 46 % артефактов; v3 — пересчёт |
| SA | акустический детектор | точность ≥ 0.90 на ≥ 100 словах | **не пройдено**: 0.358 |
| Натуральность | парные предпочтения | ловушки «файл против себя» | харнесс есть, слушателей не было |

**Следствие для N5.** Пока SA-измеритель невалиден, гейт N5 не измерим.

## Валидность метрик — отдельное исследование

**Дизайн.** Системы: Silero, Track A (заморожен), D1, внешние Qwen3-TTS /
CosyVoice3, copy-synth, деградированные версии. Человеческая оценка: парные
предпочтения сейчас; P.808 — после панели слушателей. Абсолютный UTMOS не
подменяет MOS.

### Внешний baseline

**Обязательные системы в сравнительных таблицах D1:**

- Silero raw и Silero+frontend
- Track A (`runs/mel_stress_v01_s4`) — вторичная точка
- Qwen3-TTS 0.6B и 1.7B
- CosyVoice3
- Copy-synth frozen Qwen3-TTS 12Hz
- Continuous N2 S1 — отрицательный контроль (если нужны listen wavs)

Обвязка Silero: `scripts/39_external_baseline_eval.py`. Лицензии — в реестр до
публикации.

### Статус P.808

Пилот P.808 отложен до панели слушателей. Рабочий инструмент — парные
предпочтения (`scripts/51_preference_test.py`). MOS без панели помечается как
**не измеренный**.

## Правила измерения

Обязательны для всех гейтов Track N / D1.

1. **Никаких решений по абсолютному UTMOS.**
2. **Всегда рядом copy-synth topline** того кодека, которым пользуемся.
3. **Seeds и CI95** на всех заявляемых улучшениях.
4. **Одна переменная за раз** в абляциях.
5. **Замороженные тестовые наборы с хешами** до серии.
6. **Внешний baseline обязателен** в любой публикуемой таблице.
7. **Домены train/infer совпадают** (packing text+codes, frontend parity).
8. **Отчётность: mean, median, CI95 и выбросы.**
9. **Free-running > teacher-forced** для promotion (Ф6).
10. **Любой inference пишет wav** под `out/<plan_slug>/…` + `listen_index.json`.

## Гейты N-серии (сохранены) и D-серия (D1)

Порядок соблюдается; пропуск не допускается.

### D-гейты этапа D1

| Гейт | Название | Критерий |
|------|----------|----------|
| **D0** | Frozen codec пригоден | Copy-synth CER Qwen3-TTS 12Hz на E2-compatible наборе **≤ 0.073**; DER на `bank_entity` не хуже зафиксированного codec anchor; bit-identical re-encode. При FAIL — LM не учим |
| **N2 (D1)** | Oracle / 32-utt content | Free-running CER ≤ `copy_synth CER + 0.03` на той же подвыборке; CI отдельно от trivial baselines; нет runaway/repetition; CB0 entropy/utilization не коллапсировали; text-usage на free-running ASR PASS. При FAIL — **запрет** 1h/5h/full |
| **N3 (D1)** | Full-current intelligibility | Hard-set CER не хуже copy-synth topline более чем на 3 п.п. с CI95; `val100 CER ≤ 0.15` — sanity floor. FAIL → ремонт архитектуры, не авто-D2 |
| **D2-GO** | Масштаб 500+ ч | Только при D0 PASS + N2 PASS + N3 PASS + нет sampler/EOS collapse + юридически допустимый корпус |

Continuous N2 FAIL (FR R² −6.64) остаётся в истории как контроль того же имени
гейта на другом тракте — не перезачёт и не «почти прошло».

### Полная N-серия (долгосрок)

| Гейт | Название | Критерий |
|------|----------|----------|
| **N0** | Свой токенизатор пригоден | Phase 0 GO на **своём** кодеке (post-D1); для D1 роль N0 по смыслу исполняет **D0** на frozen Qwen3-TTS |
| **N1** | Стриминг корректен | Cache-decode ≡ full float32 (≤ 1e-3), без всплеска на границах — для своего/streaming кодека |
| **N2** | Вторая стадия учится | Content на малом подмножестве; см. D1-форму выше |
| **N3** | Разборчивость | Hard-set vs copy-synth ≤ +3 п.п. CI95 |
| **N4** | Критические спаны | DER = 0 и EER ≤ 2% на `bank_entity` **v2+** (с аудитом) |
| **N5** | Ударение | SA ≥ 0.95 при валидированном измерителе; сейчас гейт не измерим |
| **N6** | Натуральность | Парное предпочтение vs Silero; MOS только после P.808 |
| **N7** | Устойчивость | Повторы/пропуски ≤ 2%; long vs short CER ≤ +3 п.п. |
| **N8** | Латентность | TTFB ≤ 300 мс тёплый, RTF ≤ 0.3 — **после** content gates |

Гейт **N2 — самый важный**. Continuous-пилот его провалил; D1 обязан пройти
oracle ladder до любого масштаба данных.
